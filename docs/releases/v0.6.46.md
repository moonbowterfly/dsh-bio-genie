# @dsh-bio/dsh-bio-genie v0.6.46

> **主题**：图来源记录（figorigin）——**一切图可查来源**（含发育树、示意图等无逐点映射的图）+ 设置开关。

## 新增

- **设置 → BioGenie → 图来源记录**（默认开）：开启后，**凡经 figurelib 导出的图**在落盘时
  自动写同名 `.figorigin.json` 来源记录——输入文件路径与 sha256、生成参数、工具、时间。
- **图卡「来源」按钮**（对话区每张图，含普通预览图）：点击打开侧栏「来源」查看器——
  图标识 / 生成时间 / 工具 / 备注 + 输入文件列表（sha256 前缀 + 复制路径）+ 参数。
- **`set_source_context(inputs=[...], params={...}, tool=..., note=...)`**（可选）：
  画图脚本声明输入文件后自动纳入记录（未声明时仍记录图片元数据与生成器信息）。

## 说明

- 开关存储：`<DSH_HOME>/dsh-bio-genie/config.json` 的 `figorigin`（`auto`/`off`）；
  Python 侧经 `DSH_BIO_FIGORIGIN` 环境变量读取。
- 与 fig-viewer（散点交互）互补：figorigin 管来源（一切图），fig-viewer 管点级交互（散点类图）。
- 合同细节：`docs/figorigin-v1.md`（含 BACKLOG：宿主 slot 注册时序待深挖）。

## 安装

```sh
dsh plugin --profile web add @dsh-bio/dsh-bio-genie
```

安装后重启 dsh 生效。
