# @dsh-bio/dsh-bio-genie v0.6.47

> **主题**：figorigin 推断兜底——未显式声明输入时，来源查看器展示"工作区近期数据文件（推断）"。

## 修复
- **（用户实报）** 绘制的图（如进化树）在来源面板中"没有显示任何输入文件"——
  根因：绘图脚本未调用 `set_source_context` 声明输入，此前仅记录图片元数据。
- **推断兜底**：写入 `.figorigin.json` 时若 `inputs` 为空，扫描工作目录（含一级子目录）
  近 3 小时修改的数据类文件（fasta/csv/nwk/gb/...），记为 `inferred_inputs` 并在
  来源查看器以虚线卡片 + 「推断」标注展示（不冒充精确来源）。
- **skill 引导**：bio-phylo 新增「出图时声明来源」节 + 验收标准；bio-figure 的
  交互检索节补充同一引导——绘图前声明输入成为规范动作。

## 安装

```sh
dsh plugin --profile web add @dsh-bio/dsh-bio-genie
```

安装后重启 dsh 生效。
