# @dsh-bio/dsh-bio-genie v0.6.45

> **主题**：交互检索（fig-viewer）引导默认化——让「出图即可交互」成为常态。

## 变更

- **bio-figure skill**：新增「交互检索导出（viewer）——散点类图默认开」一节——
  凡「每个点/元素对应源表数据行」的图（散点 / 火山图 / MA / 气泡图），
  导出时默认带 `viewer={...}`（该引导同时写入 8 步工作流第 7 步）。
- 效果：agent 出的散点类图将默认生成 fig-viewer sidecar → 对话图卡显示
  「交互查看」→ 用户可点击任意数据点核对原始行、并生成删除/修改的审计请求。
- **行为兼容**：底层仍为 opt-in 参数，默认出图路径与返回不变；仅 agent 引导层变化。
- 不适用场景（不开）：纯语义图（示意图 / 流程图 / 序列图谱）。

## 安装

```sh
dsh plugin --profile web add @dsh-bio/dsh-bio-genie
```

安装后重启 dsh 生效。
