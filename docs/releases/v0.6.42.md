## 修复与整理

**文档与实现一致性**

- GSEA 指引更新：`bio_gsea` 已提供，协议文档不再建议手写或外部替代。
- 溯源提醒机制描述与实际行为对齐（下一轮提醒；回复照常发出、不撤回）。
- 生长值单位说明统一（以返回体 `units` 字段为准：归一化 biomass 为 1/h；一般反应通量为 mmol/gDW/h）。
- 工具/协议计数修正（57 语义化工具 / 19 协议模板）；兼容性段落更新为双线支持（0.1.x + 0.2.0+）。

**公开信息整理**
- 移除内部开发过程痕迹（会话标识、内部文档引用、内部评估记录等）。
- 补齐第三方许可文本尾段；修正示例与仓库链接。

## 安装

```sh
# 全局装了 dsh CLI：
dsh plugin --profile web add @dsh-bio/dsh-bio-genie
# 或经 npx（无需全局 CLI）：
npx -y @deepseek-ai/dsh plugin --profile web add @dsh-bio/dsh-bio-genie
```

- 安装后**重启 dsh**；首次启动自动引导 Python 环境（uv + Python 3.12 + venv + biopython，约 1–2 分钟）。
- **0.2.0+（含官方桌面端）**：装完即有「生物基因精灵」preset，无需任何后置动作。
