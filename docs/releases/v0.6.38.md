# @dsh-bio/dsh-bio-genie v0.6.38

> **主题**：设置面板新增「蛋白设计（galatea）」页——状态面板 + **模型目录管理（可把 galatea 大模型安装到其他磁盘）**。

## 亮点

**「蛋白设计」面板页（0.6.38 新增）**

- 伴随 **dsh-bio-galatea（≥0.1.1）** 共享实例时，BioGenie 设置面板新增「蛋白设计」五态页（未安装时不出现——宿主不展示空壳 UI）：运行时版本、19 个语义化工具、检查项（`python.torch` / `runtime.mpnn` / `runtime.esmfold`）、修复建议、重探测。
- **模型目录管理（新功能）**：「模型目录」卡显示当前模型位置（默认 / 环境变量 / config.json 三源标注）、文件数与占用；支持一键把模型目录改到其他磁盘（如 `F:/Models/AI_models`）——写入 `<DSH_HOME>/dsh-bio-galatea/config.json` 的 `modelsDir` 字段（原子替换、保留其它字段、支持恢复默认）。
  - 指向**已含 `esmfold/`、`mpnn/` 的目录**（如现有模型库）→ 直接复用其中权重（免重下约 2.5GB）；
  - 指向**空目录** → 下次 `galatea_setup` 把模型下载/安装到新位置；
  - **无需重启**——galatea 下一次工具调用即按新目录解析（面板域探测有 60 秒缓存）。
- 配套：**galatea 0.1.1**——模型目录可配置（`GALATEA_MODELS_DIR` env > `config.json` > 默认），`galatea_setup` 下载目标与推理读路径全部经由新解析（node + python 双侧一致）。

## 安装

```sh
dsh plugin --profile web add @dsh-bio/dsh-bio-genie
# 桌面端（0.2.0+）：用内置 CLI --profile desktop，或在应用内「插件」页输入包名
```

## 已知边界

- 面板状态探测有 60 秒缓存：改目录后，galatea**工具调用**立即按新目录解析，但**面板显示**最多延迟 1 分钟。
- 不自动搬运旧模型：复用（目标已含模型）或重下（空目录）；手工搬移亦可（同盘 move 秒级，跨盘为大文件复制）。
- `GALATEA_MODELS_DIR` 环境变量优先级最高——设置后面板会提示「仍被环境变量覆盖」。
