# @dsh-bio/dsh-bio-genie v0.6.44

> **主题**：交互式图查看器（fig-viewer）全链上线——对话/侧边栏看图、点选查看每个数据点与元素、溯源原始文件、以审计方式删除/修改数据。
> 生物信息学「许愿式分析」宿主插件：62 个工具（57 语义化 + 5 执行器/元工具）、50 个 skill 注册条目、零依赖自举 Python 环境。

## 新增：fig-viewer 交互式科研绘图

**查看（对话 + 侧边栏）**
- 对话区回合尾图卡：每回合图产物缩略卡 + 「交互查看」入口。
- 侧边栏 Figure 查看器：适应 / 1:1 / 2×、滚轮以指针为中心缩放、拖拽平移、键盘操作；图片缺失/加载失败时回退源表浏览（标注原因，坐标点选禁用）。
- **点选查看每一个数据点/元素**：图中点击命中（8px 容差）→ 原始行数据浮窗（源表原值、聚合计数）；**元素列表面板**（工具栏「列表」）：全量元素枚举 + 搜索 + 分页（每页 300），点击任意行 → 选中并显示数据——每个元素可达。

**溯源（原始数据来源）**
- 查看器来源行：源文件 `label @ path` + 绘图脚本路径 + 「复制源路径」。
- 图卡按钮：「源数据」「脚本」（在宿主提供文件打开通道时显示，直接打开原始文件）。
- Python 侧：figview sidecar `source` 增 `path` 字段（含 rows 子 schema），导出器写入源文件路径，工具结果透出 `source_path`/`script_path` 直至前端卡片。

**数据编辑（删除/修改，审计方式）**
- 浮窗行「删除」「编辑」：标记删除 / 内联改值；编辑集面板（去重合并、删除覆盖修改、改回基准即撤销；重开显示待提交值）。
- 「生成编辑请求并回填」：结构化【图数据编辑请求】（figure_id、base_revision、source_path、source_file_sha256、source_snapshot_sha256、edits 明细（JSON 保真 + 类型标注）、审计要求）写入会话草稿（光标处插入、不覆盖已有内容）；由 agent 执行并于新 revision 导出。
- **重绘闭环**：白名单参数表单（来自 manifest）→ 【图重绘请求】→ 回填草稿；`request_redraw=false` 的图显式禁用正式回填。

**数据合同（sidecar v1）**
- `figview.py` 精确绘制捕获（Agg draw_event）、像素级坐标、bundle 原子导出与自校验；hits/rows/figview schema 全套。

## 工程与修复
- 客户端渲染面契约：`exports.inject` 加载门、Definition kind=key、typert `{ok,value}` 信封、有界读取、严格 JSON 路径（UTF-8/重复键/非有限数）。
- 安全与健壮：无原型字典（外部键）、选区折叠插入（不替换选中文字）、剪贴板异步双分支、capabilities 门、错误文案安全格式化。
- 测试：71 项客户端套件 + Python sidecar 9 项 + 全量 bench；变异台架逐防线验证。

## 安装

```sh
# 全局装了 dsh CLI：
dsh plugin --profile web add @dsh-bio/dsh-bio-genie
# 或经 npx（无需全局 CLI）：
npx -y @deepseek-ai/dsh plugin --profile web add @dsh-bio/dsh-bio-genie
```

- 安装后**重启 dsh**；首次启动自动引导 Python 环境（uv + Python 3.12 + venv + biopython，约 1–2 分钟）。
- **0.2.0+（含官方桌面端）**：装完即有「生物基因精灵」preset，无需任何后置动作。
