# @dsh-bio/dsh-bio-genie v0.6.41

> **主题**：稳定性与数据口径修复批次 + 公开文档整理。
> 生物信息学「许愿式分析」宿主插件：62 个工具（57 语义化 + 5 执行器/元工具）、50 个 skill 注册条目、零依赖自举 Python 环境。

## 修复与改进

**会话稳定性**
- 修复溯源提醒机制在特定条件下可能导致会话记录中断、最终回复未保存的问题。
- 修复 Python 代码执行超时/异常终止时错误信息被替换为无意义格式报错的问题——现在始终显示真实的超时/失败原因，并附常见原因排查建议（远程服务排队、代码未收敛等）。
- bridge 执行结果值递归规范化为 lossless JSON（numpy 标量 / -0.0 / NaN），避免大结果被值校验拒绝。

**数据口径**
- `bio_deseq2` 差异表达口径升级：median-of-ratios 文库归一化 + log2 空间 Welch t 检验 + BH-FDR；返回值新增 `method` 元数据（含 limitations 与 size_factors），新增 `out_csv` 全量结果表导出。如实声明：非完整 DESeq2（无负二项 GLM / 离散度 / 收缩），小样本用于筛选排序而非定量结论。
- `bio_primer3_design`：新增显式产物长度参数；产物长度回填修复。
- 出版级绘图配方：标签列回退修复（数据表无 `name` 列时不再报错）。
- 比对能力文档纠错：明确双序列比对支持范围 + 三条降级路线。

**输入与集成**
- 序列参数支持文件路径输入（16 处工具可直接传 FASTA 文件路径）。
- 域总览防护：integration 身份不匹配与伪绝对路径防护。
- preset「生物基因精灵」能力路由与行为行更新。

**公开文档整理**
- 清理内部流程信息；修正示例与仓库链接。

## 安装

```sh
# 全局装了 dsh CLI：
dsh plugin --profile web add @dsh-bio/dsh-bio-genie
# 或经 npx（无需全局 CLI）：
npx -y @deepseek-ai/dsh plugin --profile web add @dsh-bio/dsh-bio-genie
```

- 安装后**重启 dsh**；首次启动自动引导 Python 环境（uv + Python 3.12 + venv + biopython，约 1–2 分钟）。
- **0.2.0+（含官方桌面端）**：装完即有「生物基因精灵」preset，无需任何后置动作。
- **0.1.x**：pnpm v11 会拦插件的 postinstall（preset 文件式复制）；若打印 `[ERR_PNPM_IGNORED_BUILDS]`，按 README「安装后批准构建脚本」章批准一次。

- 其余边界见 v0.6.36 清单（qblast 排队、短序列放宽、第二层依赖按需补装等）。
